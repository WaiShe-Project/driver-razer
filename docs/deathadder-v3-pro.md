## 2. 协议

来源：openrazer `driver/razercommon.h`、`driver/razerchromacommon.c`、`driver/razermouse_driver.c`（GPL-2.0-or-later，主分支，2026-11-14 读取）。见 [PROVENANCE.md](../PROVENANCE.md)。

### 2.1 传输

| 项 | 实测结论 |
| --- | --- |
| 控制接口 | `MI_00`，顶层集合用途 `0001:0002`（鼠标），特性报告长度 91 字节（报告 ID `0x00` + 90 字节报文） |
| 打开方式 | 该集合由系统独占，以读写权限打开返回“拒绝访问”；以**访问权限 0** 打开后特性报告收发正常 |
| 收发 | 发送特性报告，约 50 ms 后获取特性报告 |
| 事务 ID | `0x1F` |
| 校验 | 报文第 2 至 87 字节异或 |

### 2.2 报文

90 字节：状态、事务 ID、剩余包数（2 字节大端）、协议类型、数据长度、命令类、命令 ID、参数 80 字节、校验、保留。

应答状态：`0x02` 成功，`0x01` 忙（openrazer 视为成功），`0x03` 失败，`0x04` 无应答，`0x05` 不支持。

### 2.3 已验证的命令

| 能力 | 类 / ID / 长度 | 参数 | 应答解析 |
| --- | --- | --- | --- |
| 固件版本 | `00` / `81` / `02` | — | 参数 0、1 为主、次版本 |
| 序列号 | `00` / `82` / `16` | — | 参数 0 起的 ASCII，实测 15 字符 |
| 电量 | `07` / `80` / `02` | — | 参数 1，0 至 255，换算为百分比 |

| 7 | 接收器在线、鼠标关机 | 所有命令应答状态 `0x04`。与“在线”可明确区分，映射为 `unavailable`（`disconnected`） |

| 13 | 切换回报率是否重新枚举 | 接收器模式下**不会**，原句柄继续可用 |
| 14 | 实体键切换 DPI 后读取是否同步 | 未测 |
| 15 | Synapse 运行时读取 | 可靠 |

| 17 | 仅后台服务运行 | 即第 2 项的环境（`razer_elevation_service` 仍在运行），行为与 Synapse 运行时相同 |
| 18 | 接口归并为端点 | 接收器的全部 HID 节点共享同一个容器 ID，可据此归并 |
| 19 | 接收器与有线同时在线 | 未测 |

### 对实现的影响

- 打开控制接口必须使用访问权限 0。这不读取鼠标的输入报告，也不影响正常输入。
- 鼠标关机时每条命令都返回 `0x04`。openrazer 的做法是重试 5 次，实测每条命令因此耗时约 390 ms。驱动应把 `0x04` 直接视为不在线，不重试。
- 每次命令往返约 50 至 60 ms，一次完整读取（电量、充电、DPI、回报率）约 250 ms。

## 7. 安全约束

- 只发送在已登记来源中出现过的命令。
- 不发送任何固件、引导加载程序相关命令。
- 写入测试只涉及 DPI 与回报率，测试前记录原值，测试后恢复。
- 抓包与日志提交前去除序列号。
